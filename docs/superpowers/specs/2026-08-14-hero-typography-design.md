# Hero Typography Refinement

## Goal

Strengthen Debi Prasad Pradhan's identity in the opening viewport while making the main headline more concise, professional, and proportionate to the rest of the portfolio.

## Approved Direction

- Increase the visual prominence of the name and Staff Software Engineer title.
- Replace the current headline with: "I build intelligent platforms engineered for real-world scale."
- Reduce the desktop headline size from its current oversized presentation and constrain its measure for cleaner line breaks.
- Reduce the mobile headline size proportionally while preserving clear hierarchy.
- Tighten the vertical spacing between identity, headline, summary, and actions.
- Preserve the system map, navigation, calls to action, and all content below the hero.

## Responsive Behavior

Desktop uses a confident but restrained headline alongside the system map. Mobile keeps the identity readable above a smaller headline, with buttons continuing to stack at full width. Fixed font sizes will be set at existing breakpoints so typography does not scale continuously with viewport width.

## Accessibility And Verification

The semantic `h1` and existing reading order remain unchanged. Automated tests, local-link checks, and desktop/mobile visual checks will confirm that text does not overlap, clip, or push essential hero content out of view.
