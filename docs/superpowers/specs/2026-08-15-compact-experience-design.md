# Compact Experience Design

## Goal

Present the complete career history in a compact, professional section that fits within one desktop viewport while preserving readable mobile behavior.

## Design

Use `From Delivery to Technical Leadership` as a full-width section title. Place the four roles below it as compact chronological rows with shared borders. Each desktop row places role metadata beside its achievements; narrow screens stack those elements. Thermo Fisher Scientific carries five concise Staff-level leadership and architecture outcomes; Oracle, Xebia, and HCL Technologies retain two focused outcomes each.
